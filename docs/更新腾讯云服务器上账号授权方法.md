
提供两种更新腾讯云服务器账号授权的操作方案，首选在云服务器直接操作的无浏览器（Headless）模式，也可在本地电脑授权后一键同步。

### 方案一：在腾讯云服务器上直接更新（无浏览器模式）

执行以下命令直接在服务器终端完成重新授权：

```bash
# 1. 进入服务器代码目录并暂时停止服务（防止配置写入冲突与端口占用）
cd /opt/agy-cc-proxy
pm2 stop agy-cc-proxy

# 2. 启动无浏览器授权模式
npm run accounts:add -- --no-browser
```

操作流程：
1. 终端会打印出一段 Google OAuth 授权链接（形如 `https://accounts.google.com/o/oauth2/v2/auth?...`）。
2. 复制该链接粘贴到本地有图形界面的浏览器中打开，登录并授权目标 Google 账号。
3. 授权完成后浏览器会尝试跳转到 `http://localhost:51121/...`（此时本地网页显示连接失败属正常现象）。
4. 复制浏览器地址栏中的**完整跳转 URL**（或其中的 `code=` 授权码），粘贴回服务器终端按回车。
5. 系统检测到相同邮箱后会自动覆写并更新 `refreshToken`。

```bash
# 3. 验证更新后的账号有效性
npm run accounts:verify

# 4. 重启 PM2 代理服务
pm2 restart agy-cc-proxy

# 5. 查看服务日志确认加载成功
pm2 logs agy-cc-proxy --lines 20
```

### 方案二：本地电脑授权后同步至腾讯云（备选快速通道）

执行本地授权并一键覆盖云服务器配置：

```bash
# 1. 在本地电脑终端调起浏览器完成授权
cd /path/to/agy-cc-proxy
npm run accounts:add

# 2. 将本地生成的 accounts.json 复制到云服务器（替换对应 IP/用户）
scp ~/.config/antigravity-proxy/accounts.json ubuntu@43.173.115.129:~/.config/antigravity-proxy/

# 3. 登录服务器或远程重载服务
ssh ubuntu@43.173.115.129 "pm2 restart agy-cc-proxy"
```

---

### 注意操作风险与边界情况

1. **授权码时效性**：Google OAuth code 有效期仅约 2 分钟，在浏览器完成授权后需尽快将 URL 贴回终端。
2. **多账号更新策略**：若绑定了多个账号，交互式命令行中选择 `(a)dd new` 并登录相同邮箱即可自动原地更新对应 Token，不会增加重复项。
3. **网络连通性**：若服务器位于境内地域节点，执行 `npm run accounts:verify` 需确保已配置出站代理环境变量 `HTTPS_PROXY`，境外节点（如腾讯云硅谷/香港）可直连。
